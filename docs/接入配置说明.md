# poverty-gateway 接入配置说明

网关地址：`https://api.pixelreeds.com`
面板（需 key）：`https://api.pixelreeds.com/`

## API Key

Key 在服务器 `/etc/poverty-gateway/keys.json` 中管理，由管理员分发。
限额参考：root 600/min，test1/test2 120/min。超限返回 429。

## 可用模型

当前对外模型（用 key 调 `GET https://api.pixelreeds.com/v1/models` 可查最新）：

- `deepseek-v4-flash-lite`
- `mimo-v2.5-lite`
- `longcat-2.0-lite`
- （可能还有自动同步发现的其他 free 模型，以 `/v1/models` 返回为准）

兼容端点（两种 baseURL 写法都行）：
- `https://api.pixelreeds.com`（不带 /v1）
- `https://api.pixelreeds.com/v1`

## 1. opencode

配置文件：`~/.config/opencode/opencode.jsonc`（全局）或项目目录 `opencode.json`

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "poverty": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "poverty-gateway",
      "options": {
        "baseURL": "https://api.pixelreeds.com",
        "apiKey": "sk-你的key"
      },
      "models": {
        "deepseek-v4-flash-lite": {
          "name": "DeepSeek V4 Flash Free",
          "limit": { "context": 128000, "output": 16384 }
        },
        "mimo-v2.5-lite": {
          "name": "MiMo V2.5 Free",
          "limit": { "context": 128000, "output": 16384 }
        },
        "longcat-2.0-lite": {
          "name": "LongCat 2.0 Free",
          "limit": { "context": 128000, "output": 16384 }
        }
      }
    }
  }
}
```

使用：`opencode` 启动后 `/models` 选 `poverty/deepseek-v4-flash-lite`，或命令行 `opencode -m poverty/deepseek-v4-flash-lite`。

## 2. Cursor

设置 → Models → 打开 "OpenAI API Key" / 自定义模型：

- **Base URL**：`https://api.pixelreeds.com`（或 `https://api.pixelreeds.com/v1`）
- **API Key**：填你的 key
- **Model**：`deepseek-v4-flash-lite` 等

Cursor 的 OpenAI 兼容接入支持自定义 Base URL + Key，填入即可。

---

## 3. Codex CLI

配置文件：`~/.codex/config.toml`

```toml
model_provider = "poverty"
model = "deepseek-v4-flash-lite"

[model_providers.poverty]
name = "poverty-gateway"
base_url = "https://api.pixelreeds.com"
wire_api = "responses"
env_key = "POVERTY_API_KEY"
requires_openai_auth = false
```

使用：`export POVERTY_API_KEY="sk-你的key"` 后运行 `codex`。

注意：Codex 0.146+ 只支持 `wire_api = "responses"`（Responses API），我们的网关已实现对应端点（`/v1/responses`）并做了兼容处理。

## 注意事项

1. **限流**：root 600/min，test1/test2 120/min。超限返回 429。
2. **模型动态变化**：网关每天自动同步 free 模型，下架的会自动摘除。以 `/v1/models` 返回为准。
3. **鉴权**：所有请求需带 `Authorization: Bearer <key>` 头（工具会自动加）。
4. **面板**：`https://api.pixelreeds.com/` 输入 key 可查看用量与代理池状态。
